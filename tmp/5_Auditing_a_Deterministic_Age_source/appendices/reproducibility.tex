\paragraph{Regenerating the audit.}
The final-trace audit can be regenerated with Python 3.12 or later:
\begin{verbatim}
python -m pip install -r requirements-analysis.txt
python analysis/analyze_v33_transcripts.py
\end{verbatim}
This script regenerates the ELP CSVs, tables, JSON summary, and sequential
figure from bundled V33 data; it resolves paths from its own location. The
complete dashboard-history export and its parser were unavailable in this
package, so the 1,704-game history statistics cannot be regenerated from it.
The live
notebook dependency is separately pinned in \path{requirements-live.txt}; live
execution additionally requires a valid competition credential and a mutable
matchmaking service, and is not needed to verify reported totals.

\paragraph{Replay boundary.}
Recorded ELP decisions and controller checkpoints can be audited from the
append-only evidence. We do not claim complete counterfactual replay: 28 human-
readable transcripts are absent, that export lacks IDs, the opponent population
and rating model evolve, and unobserved alternative actions do not exist.
Exact leaderboard ratings and missing transcript behavior therefore cannot be
reproduced. The policy action map can be inspected from the executable and the
states that are present in the evidence.

\paragraph{Known executed defect.}
The 500 telemetry rows are caught HTTP 422 failures for six stale component-test
IDs. Synthetic classification was overwritten or incomplete, and the controller
measured new telemetry before harvesting. The defect did not alter recorded
actions or ratings, but it prevented the intended telemetry abort. It is not
silently patched in the executed notebook; Appendix~\ref{app:statistics}
specifies the corrected future ordering.
