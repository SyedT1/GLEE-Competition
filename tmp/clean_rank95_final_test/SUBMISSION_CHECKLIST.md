# Submission checklist

## Identity and venue

- [ ] Every author has an active OpenReview profile.
- [ ] Review PDF and supplement contain no author name, affiliation, email,
  identifying repository URL, or identifying Agent ID.
- [ ] The IAB Competition Paper Track is selected.
- [x] The current IAB call specifies double-blind review.
- [ ] The deadline and archival/non-archival choice are confirmed in OpenReview.

## Scientific content

- [x] Headline totals match all 248 live rating rows.
- [x] The six deployed role policies are specified without requiring old notebooks.
- [x] Static Bayes calibration is not described as dynamic obedience.
- [x] Post-selection, fixed order, adaptive stopping, and missing baselines are explicit.
- [x] The confounded hidden/known persuasion comparison has been removed.
- [x] No invalid IID confidence interval appears in the manuscript.
- [x] Behavior summaries are labeled available-case and not joined to ratings.
- [x] The monitoring-order defect is reported rather than silently patched.
- [x] Related work and primary-source citations have been added.

## Artifact

- [x] Exact notebook, report, evidence JSONL, policy state, and rating CSV are bundled.
- [x] SHA-256 manifest is bundled and verified.
- [x] Analysis and live dependencies are pinned.
- [x] Analysis runs from a clean extraction-directory layout.
- [x] Analysis emits an explicit sequence-index CSV.
- [ ] Author decides and documents a license for original code; platform-log rights are checked.

## Formatting

- [ ] Compiled main content is no more than four pages.
- [ ] References, appendices, and checklist follow the main content.
- [ ] PDF is US Letter with embedded fonts and no style modifications.
- [ ] No errors, unresolved references, overfull tables, or clipped figures remain.
- [ ] Every URL and bibliography entry is checked in the compiled PDF.
- [ ] Funding and competing interests are correct for the submission stage.
- [ ] Authors verify all prose, figures, data, citations, and any disclosed tool assistance.

## Upload

- [ ] Upload the newly rebuilt ZIP and PDF, not an earlier file with the same name.
- [ ] Enter the Agent ID in the OpenReview form only where organizers request it.
- [ ] Open the uploaded PDF and supplement from OpenReview after upload.
