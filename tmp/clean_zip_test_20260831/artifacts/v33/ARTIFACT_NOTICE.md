This directory bundles the exact executed competition notebook and its exported
evidence for verification of the accompanying paper. The notebook is original
author code; the logs contain observations returned by the GLEE Competition
service. No additional license is asserted here for platform-generated content.
Redistributors must check the competition terms and remove credentials or
personal data before further release. The supplied files contain no API key.

modified to conceal its documented telemetry-order defect. To preserve
double-blind review, the bundled evidence replaces the submitting agent UUID
and dashboard name with `ANONYMIZED-AGENT-ID` and `ANONYMIZED-AGENT`; no game
state, action, timestamp, score, or controller record is changed.
